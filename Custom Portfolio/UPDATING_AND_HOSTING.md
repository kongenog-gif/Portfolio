# Updating Your Portfolio & Free Hosting Instructions

## 1️⃣ Where to update your data

All the visible text on the site lives in **`index.html`**. Look for the placeholders wrapped in square brackets and replace them with your own information:

```html
<h1>[YOUR NAME HERE]</h1>
<p>Welcome to my portfolio – a glimpse of my work and skills.</p>
```

- **Name** – replace `[YOUR NAME HERE]` with your full name.
- **Bio** – replace `[A SHORT BIO GOES HERE]` in the *About* section.
- **Projects** – each project card contains a title and description. Edit the `<h3>` and `<p>` inside the `.card` elements.
- **Contact** – change the `mailto:` address in the *Contact* section.

You can also customise the colour palette by editing the CSS variables at the top of **`style.css`**:

```css
:root {
  --bg-primary: #020408;   /* background */
  --bg-secondary: #0a101f; /* secondary background */
  --accent-gradient: linear-gradient(135deg, #4285f4, #a142f4);
  --text-primary: #ffffff; /* text colour */
}
```

## 2️⃣ Deploying for free

### 📦 GitHub Pages (static site hosting via a Git repo)
1. **Create a repository** on GitHub (public or private – free for public).
2. Clone the repo locally or copy the whole `Custom Portfolio` folder into the repo folder.
3. Commit and push the files:
   ```bash
   git add .
   git commit -m "Initial portfolio"
   git push origin main
   ```
4. In the GitHub repo settings, go to **Pages** → **Source** and select the `main` branch (root).
5. GitHub will publish the site at `https://<username>.github.io/<repo>/`.

### 🚀 Netlify (drag‑and‑drop or Git integration)
**Option A – Drag & Drop**
1. Sign up at https://app.netlify.com and create a new site.
2. Drag the entire `Custom Portfolio` folder onto the upload area.
3. Netlify will give you a free sub‑domain like `awesome-portfolio.netlify.app`.

**Option B – GitHub integration**
1. Connect your GitHub account in Netlify.
2. Choose the repository you created for the portfolio.
3. Netlify automatically detects it as a static site and deploys it.

Both services provide HTTPS automatically and handle CDN caching, so your portfolio loads quickly worldwide.
